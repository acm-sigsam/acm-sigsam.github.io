RAGlib, by Mohab Safey El Din (PolSys, LIP6), is a Maple package for the study of real solutions of polynomial systems of equations and inequalities, such as testing whether the real solution set is empty or computing sample points in each of its connected components; it is built upon Jean-Charles Faugère's FGb library and its Maple interface (homepage).
