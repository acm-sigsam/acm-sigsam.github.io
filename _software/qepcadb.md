QEPCAD B is an interactive command-line program written in C/C++ and based on the SACLIB library, implementing quantifier elimination by partial cylindrical algebraic decomposition; the 'B' version, by Christopher W. Brown, extends the original QEPCAD of Hoon Hong, and it is now distributed with the Tarski system while remaining available as a separate executable and library (homepage).
