Hecke is a software package for computational algebraic number theory, written in Julia on top of Nemo and AbstractAlgebra, and part of the OSCAR project (README, documentation). It handles number fields, orders and ideals, class and unit groups, class field theory, associative algebras, and quadratic and Hermitian forms and lattices (README).
