This package contains algorithms for computations in commutative algebra closely related to the Groebner algorithm for ideals and modules. There are facilities for local computations, using a modern implementation of Mora's standard basis algorithm, that works for arbitrary term orders. This reflects the full analogy between modules over local rings and homogeneous (in fact H-local) modules over polynomial rings.
