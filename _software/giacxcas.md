Giac is a C++ library, the computer algebra kernel, which can also be used from Python, Java and Javascript programs; Xcas is an interface to it for computer algebra, function graphs, interactive 2-d and 3-d geometry, spreadsheet, statistics and programming (homepage). The project began in 2000, following the development of the CAS for HP calculators, and Giac is the CAS of GeoGebra and of the HP Prime calculator (homepage).
